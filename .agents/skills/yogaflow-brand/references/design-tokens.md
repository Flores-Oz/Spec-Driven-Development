# Tokens visuales

| Token | Valor | Uso |
|---|---|---|
| `--bg` | `#F7F4ED` | Fondo app |
| `--forest` | `#234B3D` | navegación, CTA |
| `--sage` | `#A7B8A4` | apoyo, llenado |
| `--terra` | `#C9745B` | alertas y espera |
| `--paper` | `#FFFEFA` | superficies |
| `--muted` | `#77776F` | secundarios |
| `--border` | `#E2E6DB` | divisores |

- Radii: 8/14/20 px según jerarquía.
- Espaciado base: múltiplos de 4 y 8 px; superficies generosas, listas compactas.
- Serif para títulos grandes; sans para controles y cuerpo.
- Contraste alto para texto principal; nunca usar salvia claro para texto sobre blanco.
- Acciones primarias siempre de alto contraste; foco teclado de 3px.
- No depender de fuentes CDN para funcionar en modo local.

Referencias visuales revisadas: `references/diseno-administradora.png` y `references/diseno-alumna.png` en la raíz del repositorio.
